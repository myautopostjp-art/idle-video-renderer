Idle Video Renderer

An automated system for generating and publishing relaxing ambient videos to TikTok.

About This Application

Idle Video Renderer is a fully automated content creation and publishing system designed to generate high-quality relaxing ambient videos — such as cozy room scenes, fireplace ambience, and nature-inspired backgrounds — and distribute them to TikTok on a scheduled basis.

The system uses AI-generated imagery and background music to produce unique, visually calming content intended for productivity, study, and relaxation purposes. All content is original and created programmatically using licensed AI generation tools.

Features

🎨 AI Image Generation

Unique background scenes are generated using Google Gemini's image generation API, ensuring fresh and original visuals every time.

🎵 Original BGM

Background music is composed using AI music generation tools, producing royalty-free, relaxing audio tracks.

📹 Automated Video Rendering

Videos are rendered automatically using FFmpeg via GitHub Actions, combining imagery and music into polished final outputs.

📱 TikTok Publishing

Completed videos are automatically published to TikTok using the official TikTok Content Posting API with scheduled posting capabilities.

TikTok API Integration

This application integrates with the TikTok Content Posting API to automate the scheduling and publishing of relaxing ambient videos. The integration is used solely for content creation and distribution purposes.

API permissions requested:

  • video.publish — To publish videos to the connected TikTok account
  • video.upload — To upload video files for publishing
  • user.info.basic — To verify account identity and publishing eligibility

All published content is original AI-generated material. No third-party copyrighted content is used. Videos are reviewed before public posting to ensure quality and compliance with TikTok's Community Guidelines.

Content Policy

All videos produced by this system are original works created using licensed AI generation tools. Content is designed to be calm, non-offensive, and suitable for general audiences. No copyrighted music, imagery, or third-party intellectual property is used.
