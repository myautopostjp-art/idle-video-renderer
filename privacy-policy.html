プライバシーポリシー

最終更新日: 2026年7月28日

本ページは、個人が運営する動画自動生成・投稿ツール「idle-video-renderer」(以下「本ツール」といいます)における、 個人情報および利用者データの取り扱いについて説明するものです。

1. 運営者について

本ツールは個人により開発・運営されています。本ツールは商用のSaaSやアプリ配布サービスではなく、 運営者自身が保有するTikTokアカウントへ、自動生成した動画コンテンツを投稿するための個人利用目的のパイプラインです。

2. 収集する情報

本ツールが取り扱う情報は以下のとおりです。

  • TikTok for Developers から発行されるAPIアクセストークン(運営者自身のTikTokアカウントに対するもの)
  • 本ツールが自動生成する動画・画像・音声ファイル(第三者の個人情報は含まれません)
  • GitHub Actions および Google Apps Script の実行ログ(エラー内容の確認のみに使用)

本ツールは、TikTokの一般利用者やその他第三者から個人を特定できる情報を収集することはありません。

3. 情報の利用目的

収集した情報は、以下の目的にのみ利用します。

  • 運営者自身のTikTokアカウントへの動画投稿の自動化
  • 本ツールの動作確認およびエラー対応

4. 第三者提供

本ツールが取り扱う情報を、第三者に販売・提供・共有することはありません。 アクセストークン等の認証情報は、Google Apps Script のスクリプトプロパティ内に安全に保管され、 本ツールの処理以外の目的で使用されることはありません。

5. 使用する外部サービス

本ツールは以下の外部サービス・APIと連携しています。

  • TikTok for Developers (Content Posting API)
  • Google Apps Script / Google Drive
  • GitHub Actions(動画レンダリング処理)
  • Pixabay API(画像素材取得)
  • Google Gemini API(BGM・画像生成、利用する場合)

各サービスの利用にあたっては、それぞれのプライバシーポリシーおよび利用規約に従います。

6. データの保管期間

生成された動画・画像・音声ファイルは、GitHub Releases および Google Drive 上に保管され、 運営者の判断により随時削除される場合があります。
